保存在设备上的信息

Still 没有独立的 Still 账号，也没有开发者自建的 App 服务器。个人目标、任务、反思、专注记录、已保存的个人计划和家长每周反思保存在你的设备上，Still 不会通过家庭 CloudKit 共享同步这些个人记录。

App 也会保存偏好、当前身份、Apple 提供的不透明应用选择、控制设置，以及运行你所选功能需要的家庭本机缓存或未发送编辑。根据你的 Apple 设置，设备备份可能包含本机 App 数据。

与家庭共享的信息

家庭模式使用 Apple iCloud 和私密 CloudKit 共享。共享拥有者和受邀并接受邀请的参与者可以访问家庭记录；这些内容不会发布到 Still 公共动态。请只邀请预期家庭成员，并在 App 中查看受邀成员。

共享信息用于同步控制、显示发送与回应状态、协调计划和保留家庭任务历史，可能包括：

  • 家庭配对标识、Apple 提供的参与者标识、记录作者、版本及时间；Apple 的邀请界面也可能显示参与者信息。
  • 以 Apple 不透明 token 表示的应用、类别或网站选择，暂停／隐藏设置、时间表、时区，以及设备应用规则的回执。
  • 每日阈值规则及名称、设定分钟数、达到阈值事件和回调时间。达到事件不代表精确的使用总时长。
  • 约定、任务、日期、步骤、备注、变更请求和回应、提交以及家长反馈。
  • 家庭周计划设置，包括你填写的年龄、可用时间、协助上限、材料、活动选择、发布的计划、确认、调整请求和打卡。

屏幕使用时间报表与授权

Still 使用 Apple 的屏幕使用时间框架和系统授权。个人控制使用个人授权；孩子控制需要 Apple 为“家人共享”中的孩子提供的监护人授权。接受 iCloud 邀请本身不能证明监护关系。

打开获授权的 Apple 活动报表时，报表扩展会处理并显示 Apple 提供的用时信息，例如今日时长、近期每日总量、应用用时和人员／设备标签。处理保留在报表扩展内。Still 不会把原始报表、精确总量、应用排行榜或提取的应用身份复制到家庭 CloudKit 记录。

如果启用敏感操作确认，Face ID、Touch ID 或设备密码会通过 Apple 系统界面验证。Still 获得验证结果，不会获得生物特征模板或设备密码。

Apple 服务、购买与通知

Apple 提供 iCloud 存储与共享、屏幕使用时间授权与报表、App Store 购买和推送服务。这些服务按 Apple 的条款及隐私规则处理信息，其处理和存储地点由 Apple 决定，可能与你所在地区不同。

Still 在设备上核验 StoreKit 交易和权益状态以启用 Pro。付款资料由 Apple 处理；Still 不会获得你的银行卡号，也不会把购买历史写入家庭共享。孩子身份没有购买入口。

Apple 也可能向开发者提供销售与订阅报表。如果你在 Apple 设置中启用向开发者共享 App 分析，Apple 可能分享使用统计及诊断报表；TestFlight 另有反馈与诊断共享规则。这些 Apple 报表与家庭共享记录分开，也不需要 Still 内置分析 SDK。

可选的家长通知通过 Apple 的服务发送。可见通知为通用的达到用量限制提醒；通知元数据可能指向相关记录或规则。你可以在 iOS 设置中关闭通知。推送与后台更新不保证即时到达。

控制、导出与删除

在成人身份中，“设置 → 个人数据”提供个人工作区的导出和删除。家长每周反思和本机周计划记录分别提供自己的导出／删除操作。这些操作仅作用于操作说明对应的记录；删除本机周计划不会删除其云端共享版本。

结束家庭管理时，家长应先关闭全部家庭限制，等待孩子设备返回匹配的确认，再使用“结束管理”和 Apple 共享界面停止共享。监护人也应在孩子设备的 iOS 设置中撤销 Still 的屏幕使用时间访问权限。请让两台设备联网并重新打开 Still，以检测变化。孩子身份的恢复会同时核对配对与授权状态。

停止共享会撤销后续共享访问，不是擦除所有家庭记录、其他设备已保存副本、导出文件、截图或备份的命令。共享记录可能仍保留在拥有者的 iCloud 存储中。当前 App 没有完整的家庭云数据导出或批量删除按钮。

iCloud 拥有者可以在 iOS 设置的“Apple 账户 → iCloud → 储存空间／管理账户储存空间”查看 Still，并使用 Apple 提供的删除选项。具体选项随 iOS 和账户状态而异。如果没有找到 Still 或需要处理特定共享记录，请私下联系我们获取指引。不要假设卸载 App 或停用 iCloud 会删除所有云记录。

Still 没有为已保存记录设置统一的自动删除期限；记录可能持续保留，直至你通过相应操作删除。Apple 自行管理其服务保留期限和备份。你导出或分享的文件由你及接收者管理。Pro 结束后，导出和删除操作仍然免费。

孩子与家庭身份

家庭功能应由家长或监护人设置并监督。请向孩子说明哪些内容会被共享，只填写必要信息，避免在备注中填写健康详情、学校身份标识、地址或其他敏感资料。

孩子的任务回应和打卡是家庭共享内容，不是发给开发者的私密消息。Apple 授权是独立的系统保障，不能替代适用法律可能要求的家长许可。家长或监护人可通过私密联系入口咨询或提出有关孩子信息的请求。

广告、分析与安全

Still 没有广告或分析 SDK，不出售个人信息，也不将 App 数据与其他公司的数据关联以投放定向广告。内置 Lottie 库用于播放本地引导动画；Still 不会用它把家庭内容发送给动画服务。

App 使用 Apple 的设备保护、权限与私密 CloudKit 共享机制。获授权的家庭参与者可访问共享记录。任何安全措施都无法保证接收者不会保留或复制信息，请谨慎选择邀请对象。

本网站与支持渠道

本静态网站由 GitHub Pages 托管。我们没有添加分析工具、广告 Cookie、第三方字体或上传 App 记录的表单。GitHub 在提供 Pages 网站服务时会为安全目的记录访问者 IP 地址，无论访问者是否登录。GitHub 隐私声明说明其服务与请求信息的处理方式。

联系支持时，我们会收到你选择发送的联系方式和资料，仅用于答复请求、调查所报告问题或处理隐私请求，并在这些目的及适用法律要求所需期间保留。请只发送必要信息，不要发送密码、购买凭据、原始用时报表或孩子的私密记录。

GitHub issue 是公开的，仅适合一般且不敏感的支持问题。隐私请求和孩子的信息请使用私密联系入口。电子邮件和 GitHub 是独立服务，适用各自的隐私规则；GitHub 的处理可能涉及其他国家或地区。

隐私问题与请求

根据适用于你的法律，你可能拥有访问、更正、导出、删除、限制或反对处理信息、撤回适用许可，以及向隐私监管机构投诉的权利。请使用本页私密联系入口。我们可能会要求为理解请求和核实权限所需的最少资料，尤其在涉及孩子记录时。

我们可以协助使用 App 控制，以及处理你发给我们的信息；我们没有可读取所有用户私密 iCloud 记录的开发者后台。关于 Apple 或 GitHub 自有服务数据的请求，可能需要向相应服务商提出。所述做法发生变化时，我们会更新本页并显示生效日期。
