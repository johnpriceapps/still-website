儲存在裝置上的資訊

Still 沒有獨立的 Still 帳號，也沒有開發者自建的 App 伺服器。個人目標、任務、反思、專注紀錄、已儲存的個人計畫和家長每週反思儲存在你的裝置上，Still 不會透過家庭 CloudKit 共享同步這些個人紀錄。

App 也會儲存偏好、目前身分、Apple 提供的不透明 App 選擇、控制設定，以及執行你所選功能需要的家庭本機快取或尚未傳送的編輯。根據你的 Apple 設定，裝置備份可能包含本機 App 資料。

與家庭共享的資訊

家庭模式使用 Apple iCloud 和私人 CloudKit 共享。共享擁有者和受邀並接受邀請的參與者可以存取家庭紀錄；這些內容不會發佈至 Still 公開動態。請只邀請預期家庭成員，並在 App 中檢視受邀成員。

共享資訊用於同步控制、顯示傳送與回應狀態、協調計畫和保留家庭任務歷程，可能包括：

  • 家庭配對識別碼、Apple 提供的參與者識別碼、紀錄作者、版本及時間；Apple 邀請介面也可能顯示參與者資訊。
  • 以 Apple 不透明 token 表示的 App、類別或網站選擇，暫停／隱藏設定、時間表、時區，以及裝置套用規則的回執。
  • 每日門檻規則及名稱、設定分鐘數、達到門檻事件和回呼時間。達到事件不代表精確的使用總時長。
  • 約定、任務、日期、步驟、備註、變更請求和回應、提交以及家長回饋。
  • 家庭週計畫設定，包括你填寫的年齡、可用時間、協助上限、材料、活動選擇、發佈的計畫、確認、調整請求和打卡。

螢幕使用時間報表與授權

Still 使用 Apple 的螢幕使用時間框架和系統授權。個人控制使用個人授權；孩子控制需要 Apple 為「家人共享」中的孩子提供的監護人授權。接受 iCloud 邀請本身不能證明監護關係。

開啟獲授權的 Apple 活動報表時，報表延伸功能會處理並顯示 Apple 提供的用時資訊，例如今日時長、近期每日總量、App 用時和人員／裝置標籤。處理保留在報表延伸功能內。Still 不會把原始報表、精確總量、App 排行榜或擷取的 App 身分複製到家庭 CloudKit 紀錄。

若啟用敏感操作確認，Face ID、Touch ID 或裝置密碼會透過 Apple 系統介面驗證。Still 取得驗證結果，不會取得生物特徵範本或裝置密碼。

Apple 服務、購買與通知

Apple 提供 iCloud 儲存與共享、螢幕使用時間授權與報表、App Store 購買和推播服務。這些服務依 Apple 的條款及隱私規則處理資訊，其處理和儲存地點由 Apple 決定，可能與你所在地區不同。

Still 在裝置上驗證 StoreKit 交易和權益狀態以啟用 Pro。付款資料由 Apple 處理；Still 不會取得你的銀行卡號，也不會把購買歷程寫入家庭共享。孩子身分沒有購買入口。

Apple 也可能向開發者提供銷售與訂閱報表。如果你在 Apple 設定中啟用向開發者共享 App 分析，Apple 可能分享使用統計及診斷報表；TestFlight 另有回饋與診斷共享規則。這些 Apple 報表與家庭共享紀錄分開，也不需要 Still 內建分析 SDK。

可選的家長通知透過 Apple 服務傳送。可見通知為一般的達到用量限制提醒；通知中繼資料可能指向相關紀錄或規則。你可以在 iOS 設定中關閉通知。推播與背景更新不保證即時送達。

控制、匯出與刪除

在成人身分中，「設定 → 個人資料」提供個人工作區的匯出和刪除。家長每週反思和本機週計畫紀錄分別提供自己的匯出／刪除操作。這些操作僅作用於操作說明對應的紀錄；刪除本機週計畫不會刪除其雲端共享版本。

結束家庭管理時，家長應先關閉全部家庭限制，等待孩子裝置傳回相符確認，再使用「結束管理」和 Apple 共享介面停止共享。監護人也應在孩子裝置的 iOS 設定中撤銷 Still 的螢幕使用時間存取權限。請讓兩台裝置連線並重新開啟 Still，以偵測變化。孩子身分的復原會同時核對配對與授權狀態。

停止共享會撤銷後續共享存取，不是清除所有家庭紀錄、其他裝置已儲存副本、匯出檔案、截圖或備份的命令。共享紀錄可能仍保留在擁有者的 iCloud 儲存空間中。目前 App 沒有完整的家庭雲端資料匯出或批次刪除按鈕。

iCloud 擁有者可以在 iOS 設定的「Apple 帳號 → iCloud → 儲存空間／管理帳號儲存空間」檢視 Still，並使用 Apple 提供的刪除選項。具體選項隨 iOS 和帳號狀態而異。如果找不到 Still 或需要處理特定共享紀錄，請私下聯絡我們取得指引。不要假設解除安裝 App 或停用 iCloud 會刪除所有雲端紀錄。

Still 沒有為已儲存紀錄設定統一的自動刪除期限；紀錄可能持續保留，直到你透過相應操作刪除。Apple 自行管理其服務保留期限和備份。你匯出或分享的檔案由你及接收者管理。Pro 結束後，匯出和刪除操作仍然免費。

孩子與家庭身分

家庭功能應由家長或監護人設定並監督。請向孩子說明哪些內容會被共享，只填寫必要資訊，避免在備註中填寫健康詳情、學校身分識別碼、地址或其他敏感資料。

孩子的任務回應和打卡是家庭共享內容，不是傳給開發者的私人訊息。Apple 授權是獨立的系統保障，不能替代適用法律可能要求的家長許可。家長或監護人可透過私人聯絡管道諮詢或提出有關孩子資訊的請求。

廣告、分析與安全

Still 沒有廣告或分析 SDK，不出售個人資訊，也不將 App 資料與其他公司的資料關聯以投放定向廣告。內建 Lottie 函式庫用於播放本地引導動畫；Still 不會用它把家庭內容傳送給動畫服務。

App 使用 Apple 的裝置保護、權限與私人 CloudKit 共享機制。獲授權的家庭參與者可存取共享紀錄。任何安全措施都無法保證接收者不會保留或複製資訊，請謹慎選擇邀請對象。

本網站與支援管道

本靜態網站由 GitHub Pages 託管。我們沒有加入分析工具、廣告 Cookie、第三方字型或上傳 App 紀錄的表單。GitHub 在提供 Pages 網站服務時會為安全目的記錄訪客 IP 位址，無論訪客是否登入。GitHub 隱私聲明說明其服務與請求資訊的處理方式。

聯絡支援時，我們會收到你選擇傳送的聯絡方式和資料，僅用於答覆請求、調查所回報問題或處理隱私請求，並在這些目的及適用法律要求所需期間保留。請只傳送必要資訊，不要傳送密碼、購買憑證、原始用時報表或孩子的私人紀錄。

GitHub issue 是公開的，僅適合一般且不敏感的支援問題。隱私請求和孩子的資訊請使用私人聯絡管道。電子郵件和 GitHub 是獨立服務，適用各自的隱私規則；GitHub 的處理可能涉及其他國家或地區。
